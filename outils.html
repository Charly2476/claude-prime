Outils

Les outils utilisés pendant le cours.

  • Claude Code Assistant de code en ligne de commande, utilisé pour écrire et modifier le projet.
  • GitHub Hébergement du dépôt et historique des modifications (commits, branches, pull requests).
  • Git Gestion de versions : chaque modification est enregistrée dans un commit.
  • Cloudflare Pages Publication automatique du site à chaque mise à jour de la branche main.
